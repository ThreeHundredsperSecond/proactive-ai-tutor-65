# Пример карточки предметной карты: среднее по частотам

27 октября 2026. Рабочий проект на основе `c07` и `f07`, не проверенная единица освоения. Показывает, как начать карту вне имеющегося варианта задач. Нового экзаменационного задания и решения здесь нет.

**Официальный адрес содержания:** `6.1`, «Описательная статистика». **Требование:** `7`, фрагмент «среднее арифметическое». Это два независимых официальных кода; соответствие этой карточке — интерпретация проекта. Полные записи и версия находятся в [official.json](inputs/official.json).

**Что предлагается наблюдать:** ученик получает среднее конечного набора из точных значений и их абсолютных частот, учитывая кратности. Результатом может быть выражение «сумма произведений значения на частоту, делённая на сумму частот» и его вычисление. Одной финальной цифры недостаточно, чтобы различить несколько возможных причин ошибки.

**Условия применения:** наблюдения числовые; частоты — неотрицательные целые количества, их сумма положительна; известны точные значения, а не только интервалы. Нормировка на число строк таблицы вместо числа наблюдений — другое действие. Середины интервалов без дополнительных сведений не дают точного среднего исходного набора.

**Семейства будущих ситуаций:** список с повторениями; таблица значений и частот; графическое представление тех же частот. Смена представления может потребовать отдельного действия чтения данных. Единое умение для всех этих форм — гипотеза, не автоматически принятая эквивалентность.

**Что поддержала текущая проба:** два прохода назначили `c07` и `f07` подробному синтетическому описанию T08, оба отвергли засчитывание точного среднего по интервальным данным T10. Это проверка применения определения; реальные задачи и попытки учеников по этой карточке ещё не проверены.

**Проектный сценарий уточнения, не установленный диагноз:** ученик делит сумму значений на число строк таблицы. Возможны как непонимание частоты, так и потеря кратностей при записи. Различающий вопрос: «Сколько отдельных наблюдений представляет эта таблица и какая запись это показывает?» Ответ позволит уточнить следующий ход; сам ошибочный итог не устанавливает причину и освоение KC.

**Нерешённая граница:** считать чтение частот и построение взвешенной суммы отдельными умениями либо действиями одного умения? Пока сохраняем обе части и свидетельства раздельно; независимые показатели освоения из этой пробы не следуют.

## Уточнение рубрики для следующей версии

Не менять текущие ответы и не пересчитывать их под удобный новый эталон. В следующей версии отдельно спрашивать:

1. Какая операция наблюдается? Привести буквальную цитату.
2. Откуда известны условия: из входа, явно проверены в шаге, отсутствуют или нарушены?
3. Какая часть определения узла подтверждена и какой остаток шага им не покрыт?
4. Поддержано корректное применение, только попытка применить правило или данных недостаточно?
5. Отказ вызван отсутствием нужной цели в каталоге либо недостатком свидетельства?

Это рубрика после просмотра пробы, не заранее замороженная метрика победы. Она описывает следующий вопрос исследования; массовая генерация не требуется, чтобы зафиксировать эти различия.
