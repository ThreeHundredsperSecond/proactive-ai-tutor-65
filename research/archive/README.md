# Архив разработки

Здесь находятся исторические результаты, а не дополнительные файлы для сдачи. Текущая точка чтения — [единый EDA.ipynb](../../notebooks/checkpoint-2/EDA.ipynb); смысловая история — [research-history.md](../../docs/research-history.md).

- `notebooks/`: прежние исполненные эксперименты и пилот 50 задач.
- `replays/`: ранее сохранённое повторное исполнение чекпойнта.
- `prompting-pilot/`: входы, инструкции, raw и оценки первичного пилота.
- `working-notes/`: старые передачи и черновики сообщений/описаний публикации.
- [project-log.md](project-log.md): полный снимок прежнего AGENTS.md с хронологией. Это архив, его указания о текущем статусе не действуют.
- [link-index.md](link-index.md): актуальные цели относительных ссылок, сохранённых в исторических файлах.
- [Карта переносов и SHA-256](../../docs/archive-paths.json).

Перенесённые файлы сохранены побитово, включая старые относительные ссылки и записанные пути. Манифесты экспериментов не переписывались. Текущий сборщик EDA разрешает архивные пути через `scripts/archive_support.py` и отдельно фиксирует эту адаптацию. Исторические команды подготовки/генерации сами не обновляются и не разрешены к автоматическому запуску. Для аудита используйте сохранённые выходы и указатель ссылок; для текущего пересчёта — build_checkpoint2.py / verify_checkpoint2.py из корня репозитория.
