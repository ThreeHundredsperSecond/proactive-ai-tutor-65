# Карта с контекстом и вторым источником: протокол до выполнения

27 октября 2026. Пользователь разрешил продолжить исследование автономно, сохраняя цель: предметная карта всей профильной математики ЕГЭ. Это ограниченная исследовательская итерация, не окончательная архитектура и не запуск массового решения задач.

## Что хотим получить

Небольшой согласованный каталог кандидатов с ясными предусловиями и связанными свидетельствами. Он должен допускать разные источники задач, сохранять неизвестное и не подменять отсутствие данных отсутствием умения. Полный официальный каркас остаётся из 41 пункта; детализация этой пробы ограничена четырьмя срезами. Не объявлять их всю программу покрытой.

## Фаза 1: определения и материалы

1. До новых проб сохранить состояние файлов и этот протокол.
2. Отдельный агент готовит восемь карточек v0.2 по официальным перечням и фиксированным учебным целям: линейное уравнение; квадратное уравнение через дискриминант; область определения логарифма; координаты вектора по концам; линейная комбинация векторов с заданными коэффициентами; скалярное произведение в ортонормированном базисе; среднее по частотам; медиана. Это уточнение карточек, не независимое открытие KC. Предусловия отделены от ветвей алгоритма, разрешений и примечаний. Корпус и будущие пробы агенту не передаются.
3. Другой агент извлекает первые две задачи из каждого из трёх заранее выбранных файлов старой приватной репы на фиксированном коммите e5781a182c9e9d60430ea64b41a9cfa5149f22eb: foundations/analysis/02_logarithms.md, linear_algebra/analysis/01_vectors_basis.md, probability/analysis/03_expectation_variance.md (все внутри skills/). Не искать более удобные задачи после просмотра каталога; если структура не позволяет выделить задачи, сообщить ограничение. Сохранить точные небольшие фрагменты, пути, строки и blob SHA. Инструкции старого проекта не исполнять. Это анализ уже сохранённых материалов другого источника, не сбор нового банка и не разработка парсера.
4. Заморозить карточки до показа применений. Все конкретные умения и связи — интерпретации проекта; официальные формулировки и коды не менять.

## Фаза 2: контекст

Одинаковые карточки, одна инструкция, три известные операции. Два варианта входа: только текущий шаг либо тот же шаг плюс буквальные факты из предшествующих шагов. Для каждого варианта два новых изолированных агента; порядок случаев во втором повторе обращён. Всего четыре коротких применения, без замены ответов.

Случаи заранее фиксированы:

- №16/r1, шаг s4, узел дискриминанта; добавляем результаты s1 и s3. Гипотеза: ранее записанное квадратное уравнение должно помогать установить исходное представление.
- №2/r1, шаг s3, узел скалярного произведения на себя; добавляем результаты s1 и s2. Контроль: прежние координаты сами по себе не добавляют явно отсутствующий метрический контекст.
- №15/r1, шаг s2, узел нахождения ограничений логарифма; добавляем результат s1. Контроль: известное раньше условие не доказывает, что его заново устанавливают в текущем действии.

Источник всех трёх — сохранённый A19×3, не новая генерация решения. Это известные случаи разработки; не слепой тест. Предыдущие шаги разрешены как основание состояния, но не как свидетельство действия текущего шага. Для каждой цитаты сохранять сторону current/context. Следить за необоснованным подтверждением и переносом действий назад/вперёд, а не только числом положительных назначений.

## Фаза 3: перенос описаний на второй источник

Один отдельный агент применяет восемь замороженных карточек к шести зафиксированным учебным задачам/трассам. Это режим просмотра готовой трассы, не самостоятельное решение. Разрешены несколько карточек, частичное соответствие, отказ и сомнение. Нужны буквальные свидетельства с указанием шага. Не выводить новую карту из этих шести примеров и не расширять определения молча. Основной агент проверяет происхождение, смысловые границы и возможные ошибки источника. Один проход не измеряет устойчивость; различие источников не означает независимый тест обучения.

## Объём и правила остановки

Запланированы семь основных агентных задач: один редактор карточек, один аудитор второго источника, четыре применения контекста, одно применение к другому источнику. Допустим короткий критический разбор результатов без новых решений и без новой версии карточек. Платных API нет; 19×3 и сбор новых экзаменационных задач не запускаются.

Если условия карточки остаются двусмысленными или источник ненадёжен, сохранить проблему; не увеличивать число повторов ради согласия. Если дополнительный контекст вызывает выдуманное действие, считать это существенным дефектом процедуры. Все исходные артефакты предыдущих итераций остаются неизменными.
