# Старый промпт и нынешний A: что различается

27 октября 2026. Сопоставление инструкций и процесса, не эксперимент моделей. Старая репа приватная; приведён только исследуемый короткий промпт из принадлежащего пользователю проекта.

Источник: [CLAUDE.md:190–208](https://github.com/ThreeHundredsperSecond/math_skills_ankli_obsidian/blob/e5781a182c9e9d60430ea64b41a9cfa5149f22eb/CLAUDE.md#L190-L208), фиксированный коммит. Это сохранённая историческая инструкция, не полный журнал реально переданных запросов.

```text
Ты — эксперт по математике и педагогическому дизайну.
Тебе дан список задач из раздела "<SECTION_NAME>".

Для каждой задачи:
1. Реши пошагово. Каждый шаг — одно математическое действие.
2. Для каждого шага укажи KC (Knowledge Component):
   - kc_id: snake_case название (2-4 слова, описывает МЕТОД, не тему)
   - kc_description: что нужно уметь (одна строка, по-русски)
   - difficulty: basic / medium / hard (по задаче в целом)

Правила KC:
- Плохо: "знает производную". Хорошо: "apply_chain_rule".
- Один шаг = один KC.
- Одинаковый приём в разных задачах → одинаковый kc_id.

Формат ответа: YAML (tasks → task_id, question, difficulty, answer, steps, kcs_used).
Запиши результат в файл: skills/<subject>/analysis/<NN>_<section>.md
```

Нынешний [A.txt](../../docs/eda/04-annotation/02.1-prompting-pilot/prompts/A.txt) прочитан непосредственно из текущего проекта и не изменён.

| Сторона | Старый INGEST | Наш A и сохранённые последующие пробы |
|---|---|---|
| Вход | Список задач одного раздела, название раздела | Одна задача и её изображения в независимом контексте |
| Шаг и KC | Один шаг — один KC | Один шаг может иметь несколько KC; один KC используется в нескольких шагах |
| Смысл KC | В промпте — ID, описывающий метод; отдельной сущности Method нет | Переиспользуемое умение; целый метод отдельно представлен упорядоченными Step |
| Где согласовываются названия | Правило общего ID внутри раздела, затем отдельный агрегатор по всем analysis | A требует объединять формулировки внутри задачи; межзадачные соответствия пока отдельные предварительные интерпретации |
| Что получилось в продукте | Определения KC, упражнения с основным навыком, архивирование и замена вариантов | Сохранённые независимые решения, разметки, предварительные соответствия и воспроизводимый анализ |
| Что не установлено | Единственно правильные границы и педагогическая эффективность | То же; дополнительно нет основания объявлять один новый промпт устойчивее по A-FIPI 19×1 |

**Почему это существенно:** старый процесс не был прямой реализацией нынешних требований. Его формально более простое соответствие шага и KC делает разбор визуально понятнее, но не гарантирует единственность математической операции. Свободное слово «метод» допускает более широкие учебные единицы. Отдельная агрегация и последующий отбор карточек добавляют редакционные решения, которых нет в одном первичном ответе A.

**Чего отсюда не следует:** возврат к «один шаг — один KC» ещё не доказанный способ улучшить тьютора. Он может заставить дробить удобный шаг либо спрятать несколько умений под одной меткой. Сравнение промптов не разделяет эффект модели, корпуса, общего контекста и редакции каталога. Чтобы проверить один механизм, остальные нужно удерживать одинаковыми; [проект следующей проверки](NEXT-CHECK.md) сознательно не меняет все эти стороны сразу.
