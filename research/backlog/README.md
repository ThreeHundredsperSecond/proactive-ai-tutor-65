# Отложенные идеи

Здесь сохраняем внешние источники и возможные исследования, которые не входят в текущий план EDA. Наличие пункта не означает решение внедрять его или запускать эксперимент.

| Идея | К чему можно вернуться | Материалы |
|---|---|---|
| Каталог и граф Eedi | Сравнить небольшой фрагмент учебных целей с ФИПИ и нашими кандидатами KC; проверить, уточняют ли описания заблуждений границы действий | [Обзор Eedi/MAP](eedi-map.md), [внешний граф](https://huggingface.co/datasets/Eedi/Eedi-Misconceptions-Graph) |
| Диагностика по MAP | При переходе к ученическим попыткам рассмотреть раздельную проверку ответа и объяснения, карточки ошибок и различающие вопросы | [Обзор и отложенный план пробы](eedi-map.md) |
| DeepTutor | Посмотреть, какие решения по организации тьютора можно использовать после работы с предметными материалами; применимость пока не установлена | [HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor) |

Текущий маршрут и результаты: [EDA](../../docs/eda/README.md). Для возвращения к идее сначала определить конкретный вопрос и небольшой объём проверки; обучения, платных вызовов и массовых генераций этот список не запускает.
