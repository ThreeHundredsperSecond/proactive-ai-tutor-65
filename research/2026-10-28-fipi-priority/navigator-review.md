# Навигаторы ФИПИ: официальный промежуточный слой для карты KC

28 октября 2026. Исследовательский просмотр трёх тематически разных навигаторов профильной математики. Карты, промпты и сохранённые решения не менялись; новых решений ЕГЭ и обхода банка нет.

**Вывод:** навигаторы дают более конкретный официальный перечень действий, чем один адрес кодификатора. Его можно использовать для аудита области карты и разделения целей подготовки. Они не задают атомарные KC, зависимости освоения или достаточные свидетельства успеха ученика.

## Как применить к текущей карте — предложения проекта

Это выводы просмотра, не новые утверждения ФИПИ и не выполненный эксперимент.

1. **Проверять границы сверху вниз через действия.** К каждому официальному адресу добавить отдельный список целей навигатора с годом и страницей, затем указать: кандидат карты покрывает цель целиком, только компонент либо пока отсутствует свидетельство. Не создавать KC механически для каждой строки или каждого пересечения.
2. **Сохранить разделение моделирования и решения.** Нынешняя `lin_eq` явно исключает построение уравнения по тексту. Это осмысленная проверяемая граница: результат построения служит входом решения. Навигатор поддерживает различение учебных целей, но не доказывает независимость освоения этих действий. [Карточки v0.2](../2026-10-27-map-context-transfer/cards.md).
3. **Не приписывать источнику детализацию метода.** Нынешняя `quad_D` описывает дискриминант. Более общая цель решения квадратного уравнения не устанавливает именно этот метод и не требует раздробить его на перенос слагаемых, вычисление дискриминанта и деление. Для общей цели сохранять несколько возможных методов; для узкой карточки требовать наблюдаемого использования выбранного метода.
4. **Предусловия и свидетельство дописывать явно как проектную гипотезу.** Официальный список не определяет для нашего каталога входное состояние, допустимые представления и наблюдаемый продукт каждого действия. Условия должны иметь происхождение: условие задачи, предыдущий шаг, текущая проверка либо отсутствие данных. Предыдущий факт поддерживает применимость операции, но не доказывает её выполнение сейчас. Это продолжает [протокол работы с контекстом](../2026-10-27-map-context-transfer/PROTOCOL.md).

**Ожидаемый сценарий для тьютора:** до генерации объяснения можно различать учебную цель моделирования, выполнения метода и интерпретации результата; затем выбирать вопрос по наблюдаемому затруднению, сохраняя неопределённость. Начать достаточно с аудита уже существующих карточек и сохранённых шагов; новые решения или весь банк для этого не нужны. Полезность для реального обучения ещё не измерена.

## Версии и пределы проверки

- Коды и позиции из навигаторов относятся к **2026**. Текущий полный каркас проекта перенесён из **проекта кодификатора 2027**, сохранённого 21 октября: [происхождение](../../docs/eda/01-exam/content-map.md). Совпадение числа кода не заменяет проверку пары «год, документ, таблица, формулировка». Коды содержания и требований независимы. Официального сквозного соответствия 2026→2027 этим просмотром не установлено.
- Среднее и медиана адресованы в сохранённой карте 2027 к `content:6.1`, а не выводятся из навигатора вероятности 2026. Отсутствие темы в трёх выбранных PDF не означает её исключения из всей программы.
- Проверено доступное текстовое извлечение через web; запросы снимков первых страниц не дали доступных для просмотра изображений. Локальное скачивание для независимого рендера не завершилось из-за DNS/TLS; локальных PDF и SHA этого просмотра нет. Числа и короткие цитаты проверены по тексту PDF с привязкой к страницам; полная визуальная сверка не заявляется.
- Ссылки на учебники и внешние платформы в навигаторах есть, но их содержание и права не исследовались. Публичная доступность ФИПИ не устанавливает разрешения массово переиздавать материалы; здесь сохранены ссылки и короткие цитаты.

Место остановки: предложения требуют просмотра пользователя. Следующее конкретное действие — обсудить границу моделирование→решение и составить малый реестр целей, свидетельств и пробелов по уже сохранённым карточкам. Карта и эксперимент автоматически не продолжаются.
