# Что выяснилось после возвращения к ФИПИ

28 октября 2026. Цель остаётся прежней: карта переиспользуемых математических действий для тьютора по **всей** профильной программе. Здесь три результата: уточнён доступ к источникам ФИПИ, завершён прежний опыт с контекстом, показано, почему разные методы нельзя оценивать как нестабильность одного списка навыков.

## 1. Банк ещё на профилактике; новые банковские условия не получены

На [официальной странице](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege) сейчас объявлены работы **22–30 октября 2026**, а не до 27-го. Вход банка у инструментов завершился тайм-аутом. Найдена [официальная ссылка на открытые варианты](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege/otkrytyye-varianty-kim-ege) и архив 2026; локально скачать ZIP не удалось. Состав архива не проверен. [Журнал попыток и ограничений](source-check.json).

Получены адреса трёх конкретных задач из официальных навигаторов, чтобы вернуться к ним без нового поиска: [bank-pointers.json](bank-pointers.json). Пока это ссылки, не корпус с условиями. Скачивания через Windows не состоялось: инструмент вернул `Computer Use app approval timed out`; отказа автоматической проверки безопасности не было.

## 2. Между общей темой и KC нашёлся полезный официальный слой

Изучены навигаторы ФИПИ-2026 по текстовым задачам, неравенствам и вероятности. Они перечисляют учебные цели конкретнее кодификатора: например, различают построение уравнения по условию и решение уже построенного уравнения. Это помогает проверять, что наша карта не потеряла этап моделирования. **Одна строка навигатора ещё не равна одному атомарному KC:** рядом могут стоять целая задача, операция и метод. [Разбор с первоисточниками и страницами](navigator-review.md).

Рабочая цепочка теперь яснее: официальный адрес → учебная цель → несколько допустимых методов → действия с известным входом → свидетельства конкретных действий. Связи и детализация после официального адреса остаются гипотезами проекта. Коды навигаторов 2026 не переносятся автоматически в проект кодификатора 2027.

## 3. Два правильных метода могут давать разные наборы действий

Для предметного просмотра использованы три геометрических примера с **прежнего снимка проекта демоверсии-2027**, не из банка. В задаче с биссектрисой основной агент построил два маршрута: через углы ABC и ABD либо через ACD и смежный угол. Оба дают 77°, но в первом сумма углов треугольника применяется дважды, во втором — один раз и добавляется смежность. [Наглядный разбор](geometry-review.md).

Это меняет вопрос проверки: нам нужна последовательная разметка **одинаковых действий при сопоставимых входах**, а не одинаковые списки KC у всех правильных методов. Отдельно нужно проверять математическую допустимость самого маршрута. Иначе метрика совпадения будет штрафовать разнообразие корректных решений.

Восемь замороженных карточек геометрические основания этих примеров не описывают. Записаны пять **черновых семейств** с входом, продуктом, предусловиями и недопустимым расширением: свойство описанного четырёхугольника, площади подобных фигур, биссектриса, сумма углов треугольника, смежность. [Данные и определения](geometry-audit.json). Это не полный каталог геометрии, не полная разметка трёх решений и не изменение прежней карты. Другая агентная [рецензия](critic.md) не обнаружила явных математических ошибок, но отметила отсутствие замороженных правил свидетельства; экспертизы нет.

## Что дало продолжение прежнего исследования

Завершён [опыт с контекстом и вторым источником](../2026-10-27-map-context-transfer/README.md). На трёх известных случаях выполнены четыре изолированных применения: с предшествующими фактами и без них, по два повтора. Контекст позволил подтвердить вход квадратного уравнения в обоих повторах; в двух контрольных случаях прежнее действие не было приписано текущему шагу. Согласие статусов предусловий составило 5/9 без контекста и 9/9 с ним. Это малая проверка на известных случаях, а не общая оценка устойчивости.

На шести сохранённых учебных трассах другого проекта узкая карта дала только два сопоставления поддействий в одной трассе. По остальным явно сохранены пробелы. В частности, среднее по абсолютным частотам не назначалось как математическое ожидание только по внешнему сходству формулы. Есть [восемь читаемых карточек](../2026-10-27-map-context-transfer/cards.md) и [реестр цитат](../2026-10-27-map-context-transfer/evidence-registry.md).

## Что улучшать и чем это проверять дальше

| Хотим улучшить | Что действительно проверять |
|---|---|
| Покрытие программы | Какие официальные цели имеют определения, проверенные примеры и ещё не разобранные пробелы; широкий код сам не подтверждает покрытие |
| Воспроизводимость разметки | Совпадают ли назначения для одного действия при фиксированных определениях и сопоставимом входном состоянии; методы сравнивать отдельно |
| Обоснованность связей | Есть ли буквальное свидетельство операции и происхождение необходимых условий; уменьшать необоснованные подтверждения |
| Перенос | Работает ли замороженное определение на новых представлениях и контрпримерах, не выбранных для его написания |
| Польза тьютору | Можно ли по реальному действию ученика различить выбор отношения, применение метода и вычисление; данных учеников пока нет |

Минимизацию числа KC, максимальную атомизацию и полное совпадение всех решений не выбираем целями качества. Следующий небольшой содержательный шаг — довести несколько выбранных семейств до правил свидетельства и отказа, затем проверить на заранее отделённых примерах. После восстановления банка можно начать с трёх сохранённых указателей; этот отчёт не запускает сбор или новый пакет автоматически.
