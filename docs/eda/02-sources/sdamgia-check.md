## Источник и границы проверки

- [Страница подборок по годам](https://math-ege.sdamgia.ru/methodist).
- [Вариант 90702516](https://math-ege.sdamgia.ru/test?id=90702516&print=true), ссылка из строки «27.03.2026. Досрочная волна. Вариант ФИПИ».
- Проверяется один вариант, не весь каталог. Официальное происхождение не сверено с PDF ФИПИ. Источник полученной копии, решений, рисунков и критериев — сайт «Решу ЕГЭ»; их авторство отдельно не установлено.
- По сообщению, переданному пользователем, банк ФИПИ недоступен из-за профилактики 22–27.10.2026. Это уточнение от пользователя, не новая проверка агента. Работа с альтернативным источником согласована.

## Что получаем и как

В HTML печатной версии присутствуют условия, решения, ответы, критерии развёрнутых задач и метаданные. Часть блоков скрыта переключателями; отсутствие блока на экране не означает отсутствие в HTML. Кнопки печати/PDF сами по себе не использовались для сбора.

Формулы представлены SVG-изображениями с текстом для доступности в `alt`. Это словесное описание, не готовый LaTeX. Для одной формулы HTML содержит видимую и скрытые адаптивные версии. В структурированной копии сохраняется видимая версия; исходный HTML остаётся неизменным. Рисунки скачиваются отдельно. Никакой собственной математической транскрипции или разметки тем не добавлено.

Позиция задачи в варианте, её тип в каталоге и ID сайта — разные поля. Метки тем и ссылки «Источник» сохраняются дословно с нормализацией пробелов и технических переносов. У отдельных задач встречаются источники других лет; это не доказательство ошибки варианта или его официальности. Проверка происхождения остаётся открытой.

Результат получения и технические статистики — [отчёт о наборе](../03-dataset/sdamgia-90702516.md). Сбор воспроизводится [скриптом](../../../scripts/collect_sdamgia_variant.py).

## Использование и следующий шаг

Явная лицензия на повторное использование материалов не установлена. Ссылки и атрибуция сохранены; материалы не объявляются созданными проектом и не получают лицензию проекта автоматически. Получение одного открытого варианта не означает проверки условий массового сбора или коммерческого использования.

Следующее содержательное действие — согласовать правила разметки на сохранённых примерах. Отдельно: сверить происхождение варианта с официальным PDF; после профилактики вернуться к проверке банка ФИПИ. Эта проба не закрывает поиск источников учебной теории и не подтверждает покрытие всей программы.
