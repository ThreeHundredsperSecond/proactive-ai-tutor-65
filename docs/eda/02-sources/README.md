# 02. Источники

[Общий маршрут EDA](../README.md) · Обновлено: 21 октября 2026 года.

## Цель и результат

Найти и проверить источники задач, решений и учебной теории по всей профильной математике ЕГЭ. Результат — каталог источников с понятным происхождением и статусом получения.

## Что сделано и где результат

Есть начальные ориентиры: ФИПИ для требований и заданий; учебники и другие материалы для объяснений. Документы экзамена изучены в [этапе 01](../01-exam/README.md). Систематический поиск источников и отдельный каталог ещё не выполнены.

## Что узнали и открытые вопросы

Демоверсия не покрывает все возможные формулировки задач. Нужно выяснить, где доступны полные решения, насколько пригоден формат материалов для получения данных и какие условия использования действуют.

## Где остановились и следующее действие

Зафиксированы ориентиры. После переноса официальной карты — начать каталог: проверить открытый банк ФИПИ и кандидатов на источники решений и теории. Найденную ссылку не считать полученными данными.

## Каталог источников

Для каждой записи фиксируем: источник и ссылку, версию или дату, что берём, для чего используем, способ получения, условия использования и статус получения. Для задач и объяснений сохраняем связь с конкретным источником.

Начальная рамка: ФИПИ — для структуры экзамена и задач; учебники и другие объясняющие материалы — для содержательных объяснений. Конкретный список источников, полноту решений и пригодность форматов проверяем при сборе.
