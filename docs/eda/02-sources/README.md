# 02. Источники

[Общий маршрут EDA](../README.md) · Обновлено: 28 октября 2026 года.

## Цель и результат

Найти и проверить источники задач, решений и учебной теории по всей профильной математике ЕГЭ. Результат — каталог источников с понятным происхождением и статусом получения.

## Что сделано и где результат

Проверен альтернативный источник: [один вариант «Решу ЕГЭ»](sdamgia-check.md). Получены исходный HTML, изображения и структурированные записи; результат — в [этапе 03](../03-dataset/sdamgia-90702516.md). Проверка источника ограничена этим вариантом.

[Журнал прежних ошибок доступа к ФИПИ](fipi-bank-check.md) сохранён без изменений. При [новой проверке 28 октября](../../../research/2026-10-28-fipi-priority/README.md) официальная страница сообщает профилактику **22–30 октября**, уточняя прежнюю дату 27 октября из сообщения пользователя. Вход банка недоступен инструментам, получено 0 новых условий. Найден официальный ZIP открытого варианта 2026, но скачать его локально не удалось. Изучены три официальных навигатора 2026; [сохранены три адресных указателя банка](../../../research/2026-10-28-fipi-priority/bank-pointers.json). Ссылки не означают получения условий. В исследовании использован прежний снимок проекта демоверсии-2027, отдельно от банка и открытого варианта 2026.

Документы экзамена изучены в [этапе 01](../01-exam/README.md); проверенные материалы этого этапа не менялись. Есть начальные ориентиры на учебники и другие материалы для объяснений; систематический поиск дополнительных источников ещё не выполнен.

## Что узнали и открытые вопросы

У «Решу ЕГЭ» формулы и рисунки требуют сохранения изображений; текстовое извлечение без них теряет представление математики. Идентификатор, тип каталога, позиция в варианте и источник различаются. Происхождение, права повторного использования и математическая корректность решений не подтверждаются одним успешным скачиванием.

## Где остановились и следующее действие

Пробный набор получен. Далее согласовать разметку отдельно от сбора. После профилактики проверить банк ФИПИ; сверить вариант с официальным PDF и продолжить поиск теории. Этап поиска источников не завершён.
