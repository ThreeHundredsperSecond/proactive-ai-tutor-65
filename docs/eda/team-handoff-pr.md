# Черновик pull request

Исторический черновик описания PR. По поручению 4 ноября комплект подготовлен к публикации вместе с EDA-100 в согласованной `docs/full-ege-math-scope`. Этот файл сам по себе не означает, что PR создан; состояние публикации проверять по Git. Создание PR в `main` и слияние не поручены.

## Название

Подготовить передачу ФИПИ-EDA команде и бронирование задач

## Описание

Участникам нужна общая точка продолжения после первых 100 задач: условия, результаты, точные инструкции автора и независимого аудитора, правила проверок и метрики. Добавлены инструкция передачи, реестр всех 1148 ID с готовностью и оставшейся очередью, шаблон заявки на бронирование через GitHub Issues и локальная проверка пересечений. Бронь подтверждает координатор; офлайн-проверка не разрешает запуск.

Исторические результаты EDA-100 и исходные материалы сохраняются. Новые разборы, скачивание, внешние заявки и сообщения команде не выполняются. Воспроизведение EDA и калибровка отмечены вторым приоритетом. Универсальный исполнитель новых командных партий пока не реализован; исторические скрипты используют фиксированный каталог запуска.

Публикация включает результаты расширения до 100, на которые ссылается инструкция. Одни документы без этих зависимостей не обеспечивают продолжение работы.

## Проверка

`python scripts/fipi_team_registry.py check`; `python -m unittest discover -s tests -p test_fipi_team_registry.py`; проверка локальных ссылок и сохранности файлов завершённого запуска.
