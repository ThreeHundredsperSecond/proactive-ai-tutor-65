# Малое сравнение A и A + G1: пять задач × три повтора

26 октября 2026. Пользователь разрешил 15 новых ответов вместо всего корпуса. Этот документ зафиксирован до запуска; результаты будут отдельно в папке эксперимента, чтобы не менять исходный план задним числом.

## Дизайн

- Целевая, не случайная выборка: №2 (векторы), №3 (объёмы), №6 (корень уравнения), №7 (тригонометрия), №8 (производная по графику). Это короткие задачи с известными расхождениями границ KC; результаты не обобщаем на все 19 или ЕГЭ.
- База: сохранённые три самостоятельных решения исходного A для каждой из пяти задач из запуска 25 октября. Новый вариант: **тот же исходный A + только добавка G1**, по три независимых самостоятельных решения. Дополнительный вызов базы не делаем ради экономии.
- В отличие от одиночной пробы на готовом решении, здесь одинаковый режим: только условие и те же изображения. Готовые решения, перечень ожидаемых операций, прошлый каталог и ответы источника генераторам не передаются.
- Сохраняются все 15 новых ответов. Повторов для замены неудач нет. Параметры модели и среда не полностью контролируются; историческая база и новый запуск не дают строгого причинного доказательства эффекта G1.

## Гипотеза и оценка

G1 должна уменьшить смешение нескольких операций в одном KC без дробления арифметики и потери математического содержания. Не ожидаем решения всех групп G2–G4 одной этой правкой.

Оба варианта повторно рассматриваются основным агентом по одним правилам, без независимой экспертизы и ослепления. Сопоставление сохраняем явно, со ссылкой на raw и шаги. Предварительный набор различимых операций для просмотра:

| № | Операции, которые следует различать, если они выполнены |
|---|---|
| 2 | чтение координат точек; координаты вектора по концам; сложение векторов; длина |
| 3 | формула объёма конуса; формула объёма цилиндра; отношение объёмов; вычисление по отношению |
| 6 | равносильное устранение корня; линейное уравнение; подстановка; ОДЗ; линейное неравенство; отбор по ОДЗ |
| 7 | квадрат синуса через тождество; знак по четверти; восстановление значения по квадрату/знаку; тангенс как отношение |
| 8 | чтение нулей и знаков графика; признак максимума; отбор и подсчёт на отрезке |

Это схема оценщика, не обязательный список для каждого ответа: необязательная отдельная ОДЗ в №6 не считается пропуском корректного равносильного решения. Фактически выполненные действия проверяем по шагам. Более широкие определения, дополнительные операции и неясности отмечаем, не подгоняя их под ожидаемое количество.

Сравниваем число KC, долю составных KC, покрытие выполненных действий и обоснованность назначений по предварительной оценке. Стабильность считаем двумя способами: по множествам операций и по множествам **составов KC** (один составной KC не равен двум отдельным). Иначе одинаковое объединение операций может скрыть нестабильность их границ. Одинаковые правила применяем к старым и новым ответам; прежний Жаккар по каталогу из 155 ID напрямую не смешиваем с новыми значениями.

Точные математические рассуждения просматриваем на явные ошибки; это предварительная проверка, не новая экспертная валидация. Взаимную согласованность и техническую валидность не называем математической правильностью.
