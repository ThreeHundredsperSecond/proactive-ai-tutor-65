## Как соотнести файлы

`A_14_2.txt` — вариант A, позиция 14, повтор 2. `B_14_2.stage1.txt` — первый ответ B. `raw/*.prompt.txt` — написанная агентом вспомогательная копия промпта; в 37 из 60 есть расхождения, поэтому она не заменяет зафиксированный шаблон. `resolved_prompts/B_14_2.txt` — точная подстановка B2 с соответствующим первым ответом. Ошибки сохранения и ограничения полностью описаны в основном отчёте.

## Повторение проверки без новых генераций

В папке этих файлов выполнить Python 3:

```bash
python3 evaluate.py
python3 verify_math.py
```

Скрипты используют стандартную библиотеку и пересоздают файлы evaluation/. Они не запускают модель и не делают сетевых запросов. Семантическое сопоставление, рубрика и содержательные замечания заданы вручную внутри evaluate.py: скрипт воспроизводит подсчёт, а не независимую предметную экспертизу.

Исходный корпус находится в [data/processed/sdamgia/90702516/tasks.jsonl](../../../../data/processed/sdamgia/90702516/tasks.jsonl); версия его чтения — commit 53f182da8d1ef5a99c2880a8efaa66812212b129. Повторная копия корпуса в этой папке не создавалась. Метаданные происхождения и ограничения см. в [отчёте о наборе](../../03-dataset/sdamgia-90702516.md).
