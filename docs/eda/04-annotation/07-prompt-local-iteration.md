# Локальная доработка промпта по группам ошибок

26 октября 2026. По уточнению пользователя массовое сравнение отложено: сначала по одному показательному примеру и одному ответу на изменение. [Протокол измерений](06-kc-comparison-protocol.md) сохраняется для последующей проверки; сейчас не измеряем устойчивость и не выбираем победителя по одному ответу.

## Что хотим улучшить для тьютора

| Группа | Наблюдение и пример | Направление правки | Признак пригодного результата |
|---|---|---|---|
| G1. Границы операций | №2: чтение координат и вычисление вектора объединяются | Разделять явно выполненные операции с разными входами/результатами, сохраняя связь с шагом | Видно, где могла возникнуть ошибка чтения, а где вычитания; нет дробления каждого вычитания в новый KC |
| G2. Проверки и условия | №6: проверка ОДЗ и подстановка не тождественны | Различать виды проверок и обоснование равносильности; отмечать только выполненное | Тьютор не принимает одну проверку за другую и не приписывает отсутствующее действие |
| G3. Общность и название | №8: график функции/производной и отбор на отрезке описываются с разным объёмом | Сохранять общую операцию, контекст и ограничения отдельно в описании; объединять только синонимы | Общие действия узнаваемы, но признак максимума не смешан с чтением любого графика |
| G4. Метод и доказательный ход | №19: разные нижние оценки, разные примеры | Отличать общий метод, вариант обоснования и конкретный пример | Разные доказательные ходы сохранены; смена чисел не создаёт новый метод |

№1 — контроль переименования: две одинаковые операции с разными названиями. Его можно просматривать без новой генерации. Группы могут пересекаться; одна задача не представляет весь класс случаев. Диагностическая полезность для ученика остаётся гипотезой.

## Порядок итерации

```text
СОХРАНИТЬ исходный A без изменений
ПОДГОТОВИТЬ отдельную базу для разметки готового решения
    перенос режима работы зафиксировать отдельно от улучшений

ДЛЯ ОДНОЙ очередной группы:
    выбрать сохранённое решение, убрать прежние KC и методы
    заранее записать ожидаемое улучшение и признаки потерь
    добавить к текущему промпту один блок правил
    получить ОДИН ответ в отдельном контексте
    проверить формат, ссылки и сохранность исходного решения
    сопоставить действия, KC и методы с критериями группы

    ЕСЛИ пример удовлетворяет критериям без явных потерь:
        оставить правку в рабочем кандидате
        пометить «локально пригодно; обобщение не проверено»
    ЕСЛИ есть потери или неоднозначность:
        записать причину; изменить или откатить этот блок
        не запускать серию повторов автоматически

    сохранить вход, промпт, raw, проверку и основание решения

ПОСЛЕ локальной доработки групп:
    заморозить итоговый кандидат
    отдельно согласовать объём более широкого сравнения
    проверить три независимых повтора по протоколу 06
```

Одновременное изменение нескольких блоков затруднит объяснение результата. После следующей правки ранее просмотренные примеры можно проверить на регрессии; старый успех не переносится автоматически на новую версию.

## Первая проба: G1

Выбран №2 (`699086`), сохранённое решение r1. Выбор обусловлен составным первым шагом, а не качеством нового ответа. Прежние KC и методы удалены из входа; условие не передаётся, поскольку проверяется разметка текстового решения, а не чтение рисунка моделью.

До генерации фиксируем критерии: чтение координат, вычисление координат вектора, сложение векторов и длина вектора представлены раздельными KC; первые два привязаны к s1; составные шаги не переписаны. Одинаковые операции над двумя векторами не порождают отдельные KC. Новых математических действий и неиспользованных KC нет; один общий координатный метод сохранён.

Четыре ожидаемые операции — локальная проверка для данного примера, а не требование всегда получать четыре KC. В промпт не передаём готовый перечень этих операций. Оценка основным агентом не слепая и не экспертная.

[Материалы первой пробы](../../../data/annotation/iterations/2026-10-26-G1-vector/README.md). Сравнение с прежним решением служит иллюстрацией: базовая адаптация отдельно не запускалась, улучшение относительно неё не установлено. Это дешёвая проверка пригодности инструкции на одном случае.
