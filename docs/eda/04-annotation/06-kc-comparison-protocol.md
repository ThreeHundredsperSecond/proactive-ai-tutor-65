# Рабочий протокол сравнения разметки KC

26 октября 2026. Краткая фиксация методологического обсуждения по поручению пользователя. **План эксперимента; новые промпты, разметки и результаты ещё не получены.** Основание — [карточки расхождений](05-kc-boundary-review.md) на сохранённых 57 ответах.

## Что пытаемся получить

Устойчивое представление математических действий для предварительной карты умений: одинаковые действия сопоставляются с одинаковыми KC, содержательные различия сохраняются. Возможность различать затруднения ученика — основание для выбора детализации, но пока гипотеза, не проверенный эффект тьютора.

Ближайший эксперимент сравнивает **разметку одного и того же сохранённого решения**. Самостоятельное решение по условию, математическая корректность и полнота карты всей программы — отдельные вопросы. Исходные решения предварительно проверены агентом, не экспертами; ошибка решения может перейти в разметку.

## Критерии выделения

1. **Step:** содержательное действие с явным результатом; длина текста и число предложений не определяют число шагов.
2. **KC:** переиспользуемая операция. Указать действие, объекты/вход, результат и условия применения; приложить ID шага и фрагмент, где операция выполнена. Тема, конкретное число и ответ задачи сами по себе не KC.
3. **Граница KC:** разделять действия, если у них различаются вход/результат или условия применения и они явно представлены в решении. Не дробить каждое арифметическое действие автоматически. Сомнительную границу отмечать отдельно с основанием.
4. **Составной KC:** сохранять исходную формулировку; разрешать связь с несколькими операциями только при наличии свидетельств в шагах. Не приписывать всё, что потенциально входит в широкое название.
5. **Method:** связный способ решения, объединяющий шаги. Переименование, перестановка объяснения или другой числовой пример сами по себе не новый метод. Разные доказательные ходы сохранять.

Пример: «считать координаты концов и вычесть координаты начала» содержит две операции. Проверка ОДЗ и проверка равенства подстановкой также различаются. Их педагогическая полезность как отдельных KC ещё не установлена.

## Критерии сопоставления

```text
ДЛЯ ПАРЫ исходных KC:
    прочитать определения и подтверждающие шаги
    сравнить действие, объект/вход, результат, условия

    ЕСЛИ совпадают, различается только название:
        связать с одним кандидатом каталога
    ЕСЛИ один KC явно содержит несколько действий:
        сохранить составность и связи с отдельными операциями
    ЕСЛИ различается широта определения:
        сохранить отношение «частный / общий»
        совпадение применения не объявлять тождеством определений
    ЕСЛИ различаются операция или существенные условия:
        сохранить раздельно
    ЕСЛИ свидетельств недостаточно:
        отметить «неопределённо», не объединять молча

    записать исходные ID, решение, основание и версию правил
```

Названия и одинаковые локальные ID не являются достаточным основанием. Упоминание KC не подтверждает освоение учеником.

## Что улучшать и как измерять

Показатели считаем отдельно, без единого суммарного балла и без подбора числа KC ради метрики.

| Показатель | Расчёт и направление | Как получаем основание |
|---|---|---|
| Покрытие действий | Доля заранее выделенных содержательных действий решения, для которых назначен подходящий KC; увеличивать | Отдельный фиксированный перечень действий со ссылками на решение, затем содержательная оценка соответствия |
| Обоснованность назначений | Доля связей «шаг — KC», подтверждённых действием в данном шаге; увеличивать | Содержательная оценка каждой связи; наличие ID само по себе не подтверждение |
| Стабильность | Жаккар множеств сопоставленных операций между тремя повторами; увеличивать при сохранении покрытия и различимости | Код после явного сопоставления по одним правилам для обоих промптов |
| Дублирование | Доля неупорядоченных пар различных определений KC, признанных эквивалентными по критериям выше; уменьшать | Оценить все пары внутри каждого варианта; сохранить пары и основания. Самопары исключить |
| Смешение | Доля определений KC, объединяющих операции, которые по принятым критериям следует различать; уменьшать | Содержательная оценка с указанием смешанных операций и шагов |

Единица подсчёта определяется таблицей: действие, связь, пара определений или определение. В каждом отчёте сохранять числитель, знаменатель и число неопределённых оценок. Неопределённые случаи не засчитывать как успех; показывать отдельно. Пустой знаменатель означает «не применимо». Для Жаккара двух пустых наборов также «не применимо», а не идеальное совпадение. Пропуски и невалидные ответы учитывать отдельно среди всех ожидаемых ответов, не скрывать исключением.

**Не оптимизируем напрямую:** число KC, долю единичных KC, частоты и co-occurrence. Это описательные показатели, зависящие от состава задач и детализации. Повышение повторяемости за счёт одного KC «решать математику» не считается улучшением.

Покрытие, обоснованность, дублирование и смешение требуют смысловых решений. Пока их может оценивать отдельный агент по фиксированной инструкции, без названия варианта промпта. Его оценки и основания сохраняются как отдельный вход анализа; это не экспертный эталон. Жаккар наследует ошибки сопоставления. Доли следует показывать по задачам и в сводке, чтобы длинное решение не определяло весь результат.

## Псевдокод эксперимента

```text
ЗАФИКСИРОВАТЬ ДО ЗАПУСКА:
    критерии, версии инструкций и способ сопоставления
    решения-входы, их ID и хеши; способ выбора без отбора лучших
    задачи для доработки и задачи для последующей проверки
    одинаковые доступные настройки и материалы обоих вариантов
    отдельную инструкцию оценивания и ожидаемые артефакты

ДЛЯ КАЖДОГО решения-входа:
    отдельно подготовить перечень содержательных действий
    заморозить его до оценки вариантов
    ДЛЯ базовой и новой инструкции разметки:
        получить три ответа в независимых контекстах
        сохранить запросы и все исходные ответы, включая сбои
        проверить формат и ссылки

ПЕРЕМЕШАТЬ варианты, скрыть их названия от оценщика
ОЦЕНИТЬ действия, связи и границы KC по фиксированным критериям
СОПОСТАВИТЬ KC обоих вариантов одним способом
СОХРАНИТЬ смысловые решения, неопределённости и основания
КОДОМ ПЕРЕСЧИТАТЬ показатели из сохранённых артефактов
ПОКАЗАТЬ изменения по задачам и примеры потерь/улучшений

ЕСЛИ стабильность выросла ценой покрытия или смешения:
    не объявлять новый промпт лучше
ЕСЛИ цели конфликтуют или оценка неопределённа:
    сохранить компромисс для обсуждения
```

Возможный малый старт — пять задач из карточек, затем остальные 14. Это предложение, состав ещё нужно зафиксировать. Все 19 задач уже просматривались: оставшиеся 14 не являются независимым слепым тестом. Для последующей проверки обобщения потребуется новый отложенный набор; его сбор сейчас не запускаем.

Промпт A исходно решает задачу по условию. Если базовую инструкцию адаптировать к готовому решению, сохранить её отдельной версией и описать изменение. Новые результаты нельзя напрямую приписывать исходному A или смешивать с прежними 57 самостоятельными решениями. Если новая инструкция использует каталог, оба сравниваемых варианта должны получать одинаковый замороженный каталог; иначе сравниваем целые процессы и явно называем это так.

## Место остановки

Критерии и цели записаны как рабочая версия для следующего эксперимента. Численные пороги, окончательный состав входов и новые инструкции ещё не выбраны. Каталог не пересмотрен, генерации не выполнены. Полноту будущей карты всей математики нужно будет оценивать отдельно по покрытию официальных требований, разных типов задач и методов; один вариант из 19 задач этого не устанавливает.
