# 04. Методология разметки

## Что исследуем

Как представить математическое решение содержательными шагами и повторяющимися действиями — кандидатами knowledge components (KC). Официальная тема ФИПИ задаёт предметную область, шаг описывает действие в решении, а KC — предполагаемое умение, которое может повторяться в разных задачах. Метод связывает последовательность действий; совместная встречаемость KC сама по себе не доказывает метод или предпосылку освоения.

## Текущая методика и результат

Подготовлены предварительные разборы 100 задач ФИПИ. Первые 50 имеют редакторские соответствия основного ассистента; дополнительные 50 разобраны авторами и аудиторами в отдельных свежих контекстах. Каталог содержит 144 предварительных определения. Основные частоты рассчитаны по 98 задачам; сравнение двух групп описательное из-за различий процедуры.

- [Протокол расширения 50→200](12-expansion-50-to-200.md) — зафиксированные правила отбора, партий и контрольных точек; фактически выполнено расширение до 100.
- [Промпт аудитора](12-kc-auditor-prompt.md) — проверка решения, связи шага с KC и сопоставления с каталогом.
- [Результат 100 задач](../05-analysis/fipi-100-checkpoint.md) и [единый EDA](../../../notebooks/checkpoint-2/EDA.ipynb).
- [Работа команды](../team-handoff.md) — распределение ID, хранение результатов и накопленный анализ.

Аудитор различает существующий, новый и спорный кандидат; предложения новых узлов сохраняются отдельно от принятого каталога. Ответы агентов и согласие между ними не являются экспертным эталоном. Полная математическая экспертиза корпуса и проверка границ навыков на учениках не выполнены.

## Открытые вопросы

- Где проходит граница между одной операцией и составным маршрутом?
- Какие условия и предшествующее состояние нужны для уверенного сопоставления действия с KC?
- Какие определения перекрываются, а какие локальные кандидаты не покрыты каталогом?
- Как проверять математическую корректность и пригодность материала для конкретной учебной цели?

Предметная модель описывает требования задач. Индивидуальная оценка освоения и проверка образовательного эффекта требуют попыток учеников; текущая разметка их не заменяет.
