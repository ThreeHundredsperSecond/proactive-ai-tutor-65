# 04. Шаги решений и навыки

[Общий маршрут EDA](../README.md) · Обновлено: 21 октября 2026 года.

## Цель и результат

Получить проверяемые связи «задача → шаг решения → навык (KC)». KC описывает содержательное действие. Метод решения связывает последовательность шагов.

## Что сделано и где результат

Разметка ещё не начата. Обсуждена последовательность, но список собственных навыков не составлен.

## Что узнали и открытые вопросы

**Карта ФИПИ → задачи по темам → проверенные решения → шаги → навыки → связи задач с навыками.**

Официальная тема задаёт, где искать задачи. Навыки выделяем из содержательных действий в проверенных решениях, а не переименованием темы. У одной темы может быть несколько навыков; один навык может встречаться в разных темах.

Пример только для пояснения, не готовая разметка: «Тригонометрические уравнения» → задача с отбором корней → преобразование выражения, решение уравнения, отбор корней → кандидаты на соответствующие навыки. Детализация и способ предметной проверки остаются открытыми.

## Где остановились и следующее действие

Сейчас изучаем официальное содержание как есть. После сбора пробного набора — разобрать и проверить несколько решений, записать наблюдаемые действия и предложить навыки для обсуждения. Исходные коды и формулировки ФИПИ сохранять отдельно от нашей разметки.

## Ограничения интерпретации

Частоты и co-occurrence KC считаем **после разметки**. До неё изучаем состав исходных материалов: темы, типы задач, форматы ответов, наличие решений, пропуски и дубли.

Совместная встречаемость даёт кандидатов на методы, но не доказывает смысл, порядок или зависимости навыков. Проверяем их по решениям и предметной экспертизе. Выводы о частотах относятся к нашему набору, а не автоматически ко всему экзамену.
