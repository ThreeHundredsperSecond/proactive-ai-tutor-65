# 03. Набор данных

[Общий маршрут EDA](../README.md) · Обновлено: 23 октября 2026 года.

## Цель и результат

Собрать задачи, ответы, решения и объяснения с прослеживаемыми источниками; предметную проверку решений отличать от проверки извлечения.

## Что сделано и где результат

Получен пробный набор из 19 задач одного варианта «Решу ЕГЭ». Сохранены исходный HTML, изображения, структурированные записи, локальный просмотр и технические статистики. [Реестр, проверки и ограничения](sdamgia-90702516.md). Скрипт позволяет восстановить записи без сети.

## Что узнали и открытые вопросы

Условия, ответы и решения есть у всех 19 задач; критерии — у семи. Формулы и рисунки требуют сохранения изображений, скрытые адаптивные версии формул дают технические дубли. Официальное происхождение варианта, полная математическая корректность и права повторного использования не подтверждены. Это набор разработки, не независимая проверочная выборка. Учебная теория пока не собрана.

## Где остановились и следующее действие

Сбор одного пробного варианта выполнен. Собственных тегов, связей с ФИПИ, шагов и KC нет. Следующее действие — обсудить с пользователем схему разметки на этих задачах, затем проверить её на примерах. Текущий набор не доказывает покрытие всей программы; расширение источников и предметная проверка продолжаются отдельно.
