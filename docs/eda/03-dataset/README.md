# 03. Набор данных

[Общий маршрут EDA](../README.md) · Обновлено: 21 октября 2026 года.

## Цель и результат

Собрать задачи, проверенные решения и объяснения с прослеживаемыми источниками. Сначала пробный набор по всем разделам, затем уточнение структуры данных и расширение сбора.

## Что сделано и где результат

Учебный набор ещё не собран. Обзор документов ФИПИ не является готовым датасетом задач.

## Что узнали и открытые вопросы

Разные задачи содержат текст, формулы, таблицы и рисунки. Нужно определить способ их хранения, наличие эталонов и фактическое покрытие официальных тем. Размер набора и формат хранения пока не выбраны.

## Где остановились и следующее действие

Ожидаем официальную карту и проверку источников. Затем собрать пробные примеры по всем разделам; для каждого сохранить источник, исходное условие, доступный ответ, решение и связь с официальным содержанием. Недостающие материалы помечать явно. Проверочный набор отделять от примеров разработки.
