# 03. Набор данных

[Общий маршрут EDA](../README.md) · Обновлено: 31 октября 2026 года.

## Цель и результат

Собрать задачи, ответы, решения и объяснения с прослеживаемыми источниками; предметную проверку решений отличать от проверки извлечения.

## Что сделано и где результат

**31 октября:** получен [локальный снимок банка профильной математики ФИПИ](../../../data/fipi/2026-10-31-profile/README.md): 1148 условий, исходные страницы, MathML, 443 файла изображений и доступные метаданные. Есть JSONL и локальные HTML-карточки. Сбор шёл партиями по 50 задач с проверкой каждой страницы и выборочным браузерным рендером между партиями. Один дефект исходного символа маркирован; исправлено отображение старого MathML `mfenced` в просмотре, исходники сохранены. Это корпус условий, без полученных ответов, решений и новой KC-разметки. Подробные проверки и ограничения находятся рядом с данными.

Получен пробный набор из 19 задач одного варианта «Решу ЕГЭ». Сохранены исходный HTML, изображения, структурированные записи, локальный просмотр и технические статистики. [Реестр, проверки и ограничения](sdamgia-90702516.md). Скрипт позволяет восстановить записи без сети.

## Что узнали и открытые вопросы

Условия, ответы и решения есть у всех 19 задач; критерии — у семи. Формулы и рисунки требуют сохранения изображений, скрытые адаптивные версии формул дают технические дубли. Официальное происхождение варианта, полная математическая корректность и права повторного использования не подтверждены. Это набор разработки, не независимая проверочная выборка. Учебная теория пока не собрана.

## Связь с разметкой

На основе снимка ФИПИ подготовлены предварительные разборы 100 задач; методика и границы проверки описаны в [разделе разметки](../04-annotation/README.md). Помеченный дефект исходника `697AC9` сохранён в журнале сбора. Наличие условий всех задач не означает наличие проверенных решений или полного покрытия программы разметкой.
