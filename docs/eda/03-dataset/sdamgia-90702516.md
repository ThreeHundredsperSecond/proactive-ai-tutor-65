## Как проверили сохранность

- Проверены число записей, непрерывность позиций, уникальность ID, непустые блоки условий, ответов и решений.
- Проверены локальные файлы, размеры, SHA-256 и возможность разобрать SVG как XML. Отдельно проверены пути всех изображений в локальном просмотре; внешних изображений в нём не осталось.
- Скрипт повторно запущен с `--offline`: восстановление не требует сайта. Результирующие JSONL, статистики и HTML детерминированы для того же снимка и манифеста.
- При текстовом разборе исходника найдены адаптивные дубли формул. Удалены только скрытые варианты `tex-span`, видимая версия сохранена изображением. Скрипт не пытается считать словесный `alt` готовым LaTeX.
- Ответы первой части прочитаны из отдельных блоков; во второй части — из заключительного абзаца решения. Критерии хранятся отдельно и не подменяют ответ.
- Сверка структуры и наличия файлов не равна полной визуальной и математической проверке. Визуально просмотрены отрисованные локальные копии всех 9 рисунков условий/решений и трёх формул (№1, 6, 13): подписи и математические знаки читаются. Полная вёрстка HTML в браузере в этой среде не проверена.

## Выводы и ограничения для тьютора

Источник пригоден для небольшого пробного корпуса «задача — ответ — решение — критерии» с прослеживаемыми ссылками. Извлечение только плоского текста теряет рисунки и превращает формулы в описания для доступности; исходное представление необходимо сохранять.

Номера внутри варианта, типы каталога и ID не взаимозаменяемы. Ссылки «Источник» отдельных карточек включают другие годы и подборки. До сверки с официальным документом не считаем эти данные доказательством происхождения всего варианта.

Отсутствие критериев у кратких задач — наблюдение о формате, не ошибка получения. Наличие 19 решений ещё не даёт учебную теорию, диагностику ошибок ученика или независимую предметную валидацию. Нет собственной разметки, поэтому частоты KC, совместную встречаемость, покрытие требований и всей программы не считаем.

Следующий шаг — вместе определить правила разметки на конкретных задачах из этого набора. Отдельные открытые действия: сверить официальный оригинал; проверить решения математически; уточнить условия повторного использования источника; продолжить поиск теории.

## Воспроизведение

Требуется Python 3 и `lxml` (`pip install -r scripts/requirements-data.txt`). Из корня репозитория:

```bash
# Повторное извлечение и проверки по уже сохранённым материалам, без сети:
python scripts/collect_sdamgia_variant.py --offline

# Новый снимок той же страницы (перезаписывает исходник и метаданные):
python scripts/collect_sdamgia_variant.py

# Повторить только неудачные загрузки изображений, сохранив снимок:
python scripts/collect_sdamgia_variant.py --retry-assets
```

Набор ограничен одним фиксированным вариантом; массовый сбор не реализован. Права на внешние материалы остаются у правообладателей; лицензия на их повторное использование не установлена.
