# Проактивная тьюторская система с использованием LLM и RAG

Годовой проект №65, 2026/27 учебный год.

## Проект за минуту

Делаем прототип тьютора для самостоятельной подготовки к профильному ЕГЭ по математике. Предметная область — вся программа профильного ЕГЭ по математике. Покрытие тем, типов задач и навыков анализируем по всему экзамену.

**Главная идея — тренировать методы решения через явные шаги ученика.** Задачи разбираем на действия и навыки; по попыткам ученика система должна определять затруднения, выбирать помощь и следующую практику. Цель — самостоятельное применение метода в новых задачах.

Например, неверный ответ при поиске производной может указывать на пропущенный множитель. Тьютор уточняет нужный шаг, помогает исправить его и предлагает другой пример для проверки навыка. Причина ошибки остаётся гипотезой до уточнения.

**Сейчас исследуем предметную модель:** собран снимок 1148 условий ФИПИ, подготовлены предварительные разборы 100 задач и анализ на Python. Частоты принятых связей KC рассчитаны по 98 задачам; каталог и математическая корректность всего корпуса требуют дальнейшей проверки.

**Пока открыты** детализация навыков, надёжность проверки и правила адаптации. Концепция и архитектура — рабочие версии для обсуждения с командой и куратором.

## Основания проекта

ЕГЭ выбран как понятная, структурированная задача с доступными официальными материалами и критериями проверки. Для RAG подготовим отдельный корпус учебных объяснений с учётом условий использования источников. Для всех разделов экзамена собираем задачи и учебные материалы, готовим эталоны и анализируем покрытие навыков, чтобы измерять качество работы системы.

Основной фокус — инженерный: собрать работающий MVP и проверить качество его компонентов и учебных сценариев. Если появится возможность, постараемся провести добровольный пилот со школьниками и получить обратную связь.
