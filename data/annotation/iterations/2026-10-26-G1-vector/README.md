# Одна локальная проба G1: границы операций

План: [группы и порядок итераций](../../../../docs/eda/04-annotation/07-prompt-local-iteration.md).

Один ответ на одну правку, без повторов и API. Вход — текст решения №2 r1 прежнего эксперимента, без KC/методов и без исходного рисунка. Не проверяем самостоятельное решение или способность модели прочитать графику.

**Выполнено:** один изолированный агент `/root/g1_single_v1` сохранил [raw.txt](raw.txt). Получены четыре KC на трёх неизменённых шагах, один метод. [Техническая проверка](technical-check.json) пройдена; [содержательная проверка и решение](review.md) — оставить G1 в рабочем кандидате, без вывода об устойчивости или превосходстве. [Запись запуска и SHA-256 ответа](capture.json). G2–G4 пока не запускались.

Файлы: `input.json` — замороженный вход; `baseline-adapted-A.txt` — перенос A в режим разметки готового решения; `delta-G1.txt` — единственная дополнительная правка; `candidate-v1.txt` — их объединение; `request.txt` — точный запрос; `job.txt` — техническая обвязка; `manifest.json` — происхождение и SHA-256. Новая версия не подменяет исходный A.

Подготовку можно повторить из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -X utf8 data/annotation/iterations/2026-10-26-G1-vector/prepare.py
```

Скрипт не вызывает модель, не меняет существующие замороженные файлы и не восстанавливает raw. Для повторения генерации нужно отдельно передать `request.txt` новому агенту; результат может отличаться. Базовая адаптация отдельно не генерируется, поэтому преимущество правки относительно неё здесь не измеряется.

Техническую проверку сохранённого ответа повторяет `python data/annotation/iterations/2026-10-26-G1-vector/check.py`. Она не заменяет содержательную оценку в review.md.
