# Разметка задач агентами

Это экспериментальные разборы для построения предметной модели. Они не являются готовыми экспертными эталонами или данными об освоении учениками.

- [Пилот на двух заданиях](runs/2026-10-25-agent-pilot-01/README.md): проверка пути «условие → A → агент → сохранение → проверка».
- [19 задач × 3 повтора](runs/2026-10-25-A-19x3/README.md): 57 отдельных контекстов, сохранённые исходные ответы, рецензии, сопоставление KC и воспроизводимый анализ.
- [План и определения метрик](../../docs/eda/04-annotation/04-agent-run-plan.md).
- [Ноутбук](../../notebooks/annotation-review.ipynb): выполнить ячейки сверху вниз без обращений к модели.

Исходный корпус остаётся в `data/processed/sdamgia/90702516/`, исходные страницы и изображения — в `data/raw/sdamgia/90702516/`. Вход модели содержит только условие и его изображения. Проверка, каталог и производные таблицы отделены от исходных ответов.
