## Как запускать агентов (кратко; подробно — в ТЗ)

- `exec-start` выводит сообщение для агента → инструмент Agent (`general-purpose`, `model: haiku`), промпт — это сообщение дословно → сразу `attach --agent-id … --model-requested haiku` → после уведомления о завершении `exec-finish --message "<путь, просмотренные картинки, отступления>"`. Аудитор — только после `technical_pass` автора.
- В партии 5 агенты делали увеличенные копии маленьких рисунков через `sips` во временной папке, хранили там черновики и запускали свои скрипты проверки цитат. Такие отступления записываем в журнал и README, задним числом не запрещаем.

- `gh` не установлен. Публичный Issue читается через `curl https://api.github.com/repos/ThreeHundredsperSecond/proactive-ai-tutor-65/issues/2/comments`. Писать в Issue может только пользователь.
- Не менять:
  - исторический запуск `data/annotation/runs/2026-11-02-fipi-extension-150/`;
  - реестр `data/annotation/team/`;
  - исторические скрипты: их хеши входят в проверки воспроизводимости.
- Файлы в `raw/` неизменяемы. Повтор или исправление — только через попытку.
- Не создавай ветки, не сливай и не переписывай историю без поручения. В этой ветке пользователь просил коммитить и отправлять результаты партий.
