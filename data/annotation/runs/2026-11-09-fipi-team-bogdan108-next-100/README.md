## Команды

Из корня репозитория:

```bash
RUN=data/annotation/runs/2026-11-09-fipi-team-bogdan108-next-100
python3 scripts/fipi_team_batch.py verify --run $RUN
python3 scripts/fipi_team_batch.py status --run $RUN
python3 scripts/fipi_team_batch.py exec-start  --run $RUN --role author --task <ID> --model claude-opus-5-5
python3 scripts/fipi_team_batch.py exec-finish --run $RUN --role author --task <ID> --message "<...>"
```

Подготовка выполнена командами:

```bash
python3 scripts/fipi_team_batch.py sample-plan --run $RUN \
  --selection data/annotation/team/selections/2026-11-09-Bogdan108-100-v1.json \
  --sample-seed 2026-11-09-Bogdan108-next-100-checks-v1
# затем записаны checks/batch-NN-math-expected.json
python3 scripts/fipi_team_batch.py prepare --run $RUN \
  --issue https://github.com/ThreeHundredsperSecond/proactive-ai-tutor-65/issues/4 \
  --owner Bogdan108 --model claude-opus-5-5 \
  --selection data/annotation/team/selections/2026-11-09-Bogdan108-100-v1.json
python3 scripts/fipi_team_batch.py reserve --run $RUN --confirmed-by ThreeHundredsperSecond \
  --comment-url https://github.com/ThreeHundredsperSecond/proactive-ai-tutor-65/issues/4#issuecomment-6738485103
```

Режим `--selection` в `scripts/fipi_team_batch.py` добавлен для ID вне замороженной очереди. Без него `prepare` работает как раньше. Проверка: прежний режим для номеров 51–150 во временном каталоге воспроизвёл каталог брони #2 побитово (293 файла) с точностью до имени каталога в путях изображений. `verify` и `status` по каталогу брони #2 проходят. `health-math` берёт формулировку области сверки из `manifest.json` (`check_scope`), а для манифестов без этого поля оставляет прежнюю.
