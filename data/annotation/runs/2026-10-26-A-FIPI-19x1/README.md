## Воспроизведение без модели

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/fipi_annotation_run.py capture
.\.venv\Scripts\python.exe -X utf8 scripts/check_fipi_math.py
.\.venv\Scripts\python.exe -X utf8 scripts/analyze_fipi_run.py
```

Или выполните ячейки `notebooks/fipi-annotation-review.ipynb`. В ноутбуке `TASK_POSITION` выбирает подробную карточку. Генераций и сетевых вызовов там нет. Для новых генераций нужен отдельный запуск job-файлов; повтор не гарантирует те же ответы.

В `derived/` находятся summary.json, таблицы, PNG/SVG трёх графиков, Markdown/HTML-отчёты и provenance.json. Графики строятся из CSV; provenance фиксирует входы, смысловые оценки, код и производные файлы. Ограниченная проверка перебором в math-check.json относится только к пяти перечням чисел и суммам из №19.
