Условие

Дайте развернутый ответ.

Решите неравенство log 2 ( 4 x 2 )+35 log 2 2 x−36 ≥− 1 .

КЭС: 2.5 Целые и дробно-рациональные неравенства; 2.7 Показательные и логарифмические неравенства

Ответ

x ∈ (0; 1/64) ∪ {1/2} ∪ (64; +∞)

Шаги

ID / входДействиеРезультатЛокальные KC
s1 · conditionОпределить область допустимых значений исходного неравенства.Для логарифма log₂ x необходимо x > 0; тогда 4x² > 0. Знаменатель не равен нулю: (log₂ x)² ≠ 36, то есть x ≠ 1/64 и x ≠ 64.k1
s2 · condition, s1Ввести логарифмическую переменную и преобразовать неравенство в рациональное.Пусть t = log₂ x, t ∈ ℝ, t ≠ ±6. При x > 0 имеем log₂(4x²) = 2 + 2t. Поэтому (2t + 37)/(t² − 36) ≥ −1 равносильно (t² + 2t + 1)/(t² − 36) ≥ 0, то есть (t + 1)²/((t − 6)(t + 6)) ≥ 0.k2, k3
s3 · s2Решить рациональное неравенство по знакам числителя и знаменателя.Числитель (t + 1)² положителен при t ≠ −1 и равен нулю при t = −1. Знаменатель положителен при t < −6 или t > 6 и отрицателен при −6 < t < 6. Точки ±6 исключены; t = −1 удовлетворяет неравенству. Получаем t ∈ (−∞; −6) ∪ {−1} ∪ (6; +∞).k4
s4 · s1, s2, s3Выполнить обратный переход к исходной переменной с учётом монотонности показательной функции.Поскольку x = 2ᵗ и функция 2ᵗ строго возрастает, t < −6 даёт 0 < x < 1/64, t = −1 даёт x = 1/2, t > 6 даёт x > 64. Все полученные значения удовлетворяют ОДЗ. Ответ: (0; 1/64) ∪ {1/2} ∪ (64; +∞).k5
