## Калибровка и фактическое исполнение

[Пять старых задач проверены отдельными аудиторами](calibration/README.md), без изменения старых материалов. 5/5 выбранных ответов технически валидны; один исходный ответ потребовал отдельного исправления ссылки на рисунок. 28 match, 2 uncertain и 7 замечаний — результаты агентов, не экспертный эталон и не accuracy.

До новых решений сохранено [уточнение формата v1.1](execution-protocol-v1.1.json): список допустимых ссылок и правила буквальных цитат; критерии сопоставления не менялись. Основной [промпт аудитора](auditor-prompt.txt) сохранён, форматная [обвязка](audit-format-wrapper-v1.1.txt) отдельная.

Автор и аудитор — отдельные свежие агенты `collaboration.spawn_agent`, `fork_turns=none`, по одной задаче на контекст. Автор не получает каталог и старые разборы; аудитор не получает предполагаемые назначения автора. Модель не переопределяется; её точный runtime ID недоступен и не придуман. Платный API-клиент не используется. Фактические dispatch-сообщения, ID агентов, входы, SHA, время и результаты проверки записываются в `executions/` и `validations/`. Подготовленный request сам по себе не является журналом API-вызова.

Оригинальные ответы — `raw/author/` и `raw/auditor/`. При необходимости исправления идут отдельными попытками в `attempts/`, выбор активной версии — `active-attempts.json`. Сам основной ассистент смысловые соответствия не редактирует. Новые кандидаты не консолидируются вручную.

## Проверки и контрольные точки

12 партий: по 15+15+15+5 на каждые 50 новых. После каждой — health check, перед следующей фиксируется решение продолжать. При системной проблеме следующая партия останавливается. EDA — на 100/150/200 всего. Новые отчёты не заменяют старый ноутбук.

`checks/batch-NN-sample-plan.json` задаёт визуальные/математические контрольные задачи до решений. `batch-NN-math-expected.json` содержит независимые предварительные вычисления либо честный `not_checked`; это не полная экспертиза. Код вычислений — `scripts/numeric_fipi_extension_checks.py`; версии и SHA сохранены в [monitoring-code-v1.json](monitoring-code-v1.json). Контроль математики не даёт права менять вердикты KC-аудитора.

## Команды

Из корня репозитория, Python локальной `.venv`:

```powershell
.venv/Scripts/python.exe scripts/fipi_extension.py verify-frozen
.venv/Scripts/python.exe scripts/fipi_extension.py status
.venv/Scripts/python.exe scripts/health_fipi_extension.py render --batch 1
.venv/Scripts/python.exe scripts/numeric_fipi_extension_checks.py --batch 1
.venv/Scripts/python.exe scripts/health_fipi_extension.py finish --batch 1
.venv/Scripts/python.exe scripts/report_fipi_extension.py progress --count 50 --no-notebook
.venv/Scripts/python.exe scripts/report_fipi_extension.py report --count 50
```

`prepare` повторно только проверяет уже замороженный запуск, не перевыбирает задачи. Создание агентных ответов выполняется через сохранённые dispatch-сообщения, не перечисленными офлайн-командами. `render` требует локальный Chrome; `finish` требует отдельные записи реального визуального просмотра и математических проверок, не ставит их автоматически. Checkpoint требует нужного количества завершённых пар и health checks; `--count 50/100/150` означает всего 100/150/200. Исполнение Jupyter/Chrome может потребовать запуска вне ограничения sandbox; это техническая особенность среды.

## Ограничения

Старые 50 — выборка охвата с редакторскими соответствиями; новые 150 — случайный остаток с независимым агентным сопоставлением. Накопленный корпус не объявляется репрезентативным. Частоты и единичность показываются по отдельным слоям происхождения; новые локальные предложения не равны уникальным новым навыкам. `solved` и `match` не означают предметной экспертизы. Порядок и совместная встречаемость не доказывают prerequisites или освоение.
