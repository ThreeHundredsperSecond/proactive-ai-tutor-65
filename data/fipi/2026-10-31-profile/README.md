## Просмотр и происхождение

- [Локальный каталог](index.html): карточки задач, формулы MathML и локальные рисунки.
- `raw/index.html`, `raw/page-*.html`: исходные ответы сервера в Windows-1251, без переписывания содержимого.
- `tasks.jsonl`, `tasks/<ID>.json`: структурированные записи с ID, полным GUID, страницей, URL, исходным фрагментом условия, производным HTML, MathML, буквальными метаданными ФИПИ и связями с изображениями.
- `assets/`: оригинальные файлы рисунков и формул; URL, размер и SHA-256 записаны в записях задач.
- `downloads.jsonl`: журнал успешных скачиваний — URL, время UTC, путь, размер, SHA-256. Cookie и заголовки авторизации не сохраняются.
- `summary.json`, `checks/batch-*.json`: текущий объём, проверки целостности, уникальность ID/GUID, предупреждения источника.
- `checks/render-*.json`, `checks/visual-*.jpg`, `checks/<ID>.png`: выборочный браузерный рендер и контактные листы.
- `checks/visual-review.json`: отдельный журнал визуального просмотра основным агентом; это не предметная экспертиза.

Дата снимка банка не задаёт год экзамена. `exam_year: null`: год не установлен для каждой задачи. КЭС сохранён как метаданные банка; соответствие кодификаторам 2026/2027 и KC не выводится автоматически.

## Сбор и контроль между партиями

Сеть: локальный `curl.exe` с привязкой к адресу Wi-Fi и явно заданным адресом сервера. VPN, настройки Happ и системные маршруты не меняются. Адреса относятся к этому запуску, после смены сети их нужно проверить заново.

Страница содержит 10 задач. Партия — пять страниц (50 задач), последняя партия меньше. Запросы последовательные, с паузой 0,5 с; на ошибке — до трёх попыток с увеличением задержки. Полученные файлы переиспользуются при возобновлении; отсутствие нового запроса не означает нового времени получения.

Каждая страница проверяется до перехода к следующей: заявленная страница и число задач, ID/GUID, наличие содержимого, сохранность всего текста вне служебных скриптов и точное сохранение дерева каждой формулы MathML после удаления префикса `m:`. Изображения ищутся также в вызовах `ShowPicture*`, а не только в `<img>`; каждый растр декодируется Pillow, проверяются размер и SHA-256. Неизвестные встроенные объекты, CSS-медиа и скрипты останавливают сбор для разбора.

После каждой партии проверяется весь накопленный набор на повтор ID/GUID и целостность. Перед следующей партией Chrome в отдельном headless-профиле открывает локальные карточки: при наличии выбираются задача с дефектом источника, с рисунком, с MathML, с развёрнутым ответом и задача конца партии. Проверяется загрузка каждого изображения выборки, пространство имён и ненулевая высота MathML, отсутствие горизонтального выхода за окно. Скриншоты сохраняются для просмотра основным агентом. Это целевая выборка по представлениям, не случайная оценка доли ошибок.

Новый дефект извлечения останавливает процесс. Подтверждённый дефект самого источника сохраняется буквально и маркируется `source_issues`, с предупреждением в карточке; молчаливых математических исправлений нет.

В ходе проверки обнаружено, что Chrome не отображает скобки старого элемента MathML `mfenced`. В JSON сохранена исходная семантика MathML; только HTML-просмотр раскрывает `mfenced` в `mrow` и явные `mo` для скобок и разделителей. Регрессионный пример — задача `166200`, снимок до исправления — `checks/166200-before.png`. Тестируются обычные, нестандартные, пустые и вложенные скобки; итоговые карточки пересобираются без повторного скачивания. Это исправление представления, не изменение математического условия.

## Воспроизведение

Из корня репозитория, после проверки текущих адресов сети:

```powershell
.venv/Scripts/python.exe -B -X utf8 scripts/collect_fipi_bank.py --stop-page 115 --batch-pages 5 --delay 0.5 --render-check --interface 192.168.1.2 --server-ip 80.250.169.3
```

Проверка сохранённых данных без сети:

```powershell
.venv/Scripts/python.exe -B -X utf8 scripts/collect_fipi_bank.py --audit
```

Завершающая проверка соответствия всех JSON/карточек исходникам, манифеста SHA-256 и локальных ссылок:

```powershell
.venv/Scripts/python.exe -B -X utf8 scripts/verify_fipi_snapshot.py
```

Дополнительный `--live` повторно получает страницы 1, 30, 60, 90 и 115 и сравнивает ID и полные фрагменты условий с сохранёнными. Результат — `checks/final-audit.json`. Служебные времена страницы не сравниваются с условием задачи.

Отдельный рендер партии (нужен установленный Chrome):

```powershell
.venv/Scripts/python.exe -B -X utf8 scripts/check_fipi_render.py --start 1 --end 5
```

## Ограничения

Получены условия и доступные метаданные; ответы и решения этим способом не получены (`answer` и `solution` равны `null`). Формы проверки ответа не используются для подбора эталонов. Техническая целостность не заменяет предметную экспертизу. Задачи с дефектами источника требуют отдельного просмотра до учебного использования.

Материалы сохраняются локально для работы проекта. Открытый доступ не означает установленную лицензию на массовое распространение; условия повторного использования не подтверждены. Публикации, commit/push и нового LLM-разбора задач в рамках сбора нет. Исходные корпуса, промпты и каталоги KC не изменяются.
